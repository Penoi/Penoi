## 📌 Projetos

### 📅 Academic Calendar

**Calendário acadêmico colaborativo.**

Aplicação que permite organizar e compartilhar calendários acadêmicos por meio de códigos de identificação. Cada disciplina possui um código único (por exemplo, `#math01`), permitindo que estudantes se inscrevam e acompanhem seus respectivos eventos. As alterações são sincronizadas entre todos os participantes inscritos.

**Principais características:**
- Calendários compartilhados por meio de códigos de identificação.
- Sincronização de alterações entre participantes.
- Controle de concorrência e versionamento de eventos.
- Histórico de alterações e recuperação de eventos excluídos.
- Autenticação segura e proteção contra ataques comuns.
- Testes automatizados para a API e os fluxos da aplicação.

**Tecnologias utilizadas:**
- **Backend:** FastAPI, SQLAlchemy 2 (assíncrono) e Alembic.
- **Frontend:** Jinja2 e HTMX.
- **Banco de dados:** PostgreSQL / SQLite.
- **Segurança:** Argon2, cookies httpOnly, proteção CSRF e limitação de tentativas de autenticação.
- **Testes:** pytest.

🔗 **[Repositório no GitHub](https://github.com/Penoi/academic-calendar-opensource)**

### 🌱 FieldShift — NASA Space Apps Challenge 2026

**Solução para adaptação agrícola às mudanças climáticas.**

Projeto desenvolvido em equipe durante o **NASA Space Apps Challenge 2026**, para o desafio *Field Shift: Adapting Farms with NASA Data*.

A aplicação utiliza dados ambientais e geoespaciais, incluindo informações disponibilizadas pela NASA, para auxiliar agricultores na compreensão de condições climáticas e na avaliação de estratégias de adaptação agrícola.

**Principais características:**
- Integração de dados ambientais e geoespaciais.
- Aplicação de inteligência artificial na análise de informações agrícolas.
- Desenvolvimento de APIs e integração entre serviços.
- Transformação de dados ambientais em informações úteis para o planejamento agrícola.

🔗 **[Repositório no GitHub](https://github.com/eeomts/FieldShift-NasaSpaceApps-Hackathon)**
