## 📌 Projects

### 📅 Academic Calendar
Collaborative academic calendar: each course has a unique code (e.g., `#math01`), and students who subscribe get changes synced automatically.
- Concurrency control and event versioning, change history, and recovery of deleted events
- Secure authentication (Argon2, httpOnly cookies, CSRF protection, rate limiting)
- **Stack:** FastAPI, async SQLAlchemy 2, Alembic, Jinja2, HTMX, PostgreSQL/SQLite, pytest

🔗 [Repository](https://github.com/Penoi/academic-calendar-opensource)

### 🌱 FieldShift — NASA Space Apps 2026
Team project for the challenge *Field Shift: Adapting Farms with NASA Data*. Uses NASA environmental and geospatial data, plus AI, to help farmers evaluate climate adaptation strategies.

🔗 [Repository](https://github.com/eeomts/FieldShift-NasaSpaceApps-Hackathon)
