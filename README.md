### 📌 Projeto em destaque

#### 📅 [Academic Calendar](https://github.com/Penoi/academic-calendar-opensource)
Calendário acadêmico colaborativo. Cada matéria tem um código (ex.: `#math01`). Quem ativa o código vê as datas dele no próprio calendário, e qualquer edição aparece para todos os inscritos.

- **Backend:** FastAPI + SQLAlchemy 2 (assíncrono) + Alembic para as migrações.
- **Frontend:** Jinja2 + HTMX, com interface reativa sem framework JavaScript, tema claro e escuro e layout responsivo.
- **Segurança:** senhas com hash Argon2, sessões em cookie `httpOnly`, proteção CSRF e limite de tentativas de login.
- **Colaboração:** controle de versão nos eventos, para uma edição não sobrescrever a de outra pessoa, e histórico de alterações com opção de restaurar o que foi apagado.
- **Qualidade:** testes automatizados com pytest cobrindo a API e o fluxo das páginas.
