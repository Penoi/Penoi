## 📌 Projects

### 📅 Academic Calendar

**Collaborative academic calendar.**

An application that allows students to organize and share academic calendars using unique identification codes. Each course has its own unique code (e.g., `#math01`), allowing students to subscribe and keep track of its events. Changes are synchronized across all subscribed participants.

**Key Features:**

- Shared calendars using unique identification codes.
- Synchronization of changes across participants.
- Event concurrency control and versioning.
- Change history and recovery of deleted events.
- Secure authentication and protection against common attacks.
- Automated tests for the API and application workflows.

**Technologies Used:**

- **Backend:** FastAPI, asynchronous SQLAlchemy 2, and Alembic.
- **Frontend:** Jinja2 and HTMX.
- **Database:** PostgreSQL / SQLite.
- **Security:** Argon2, httpOnly cookies, CSRF protection, and authentication rate limiting.
- **Testing:** pytest.

🔗 [**GitHub Repository**](https://github.com/Penoi/academic-calendar-opensource)

### 🌱 FieldShift — NASA Space Apps Challenge 2026

**A solution for agricultural adaptation to climate change.**

A team project developed during the **NASA Space Apps Challenge 2026**, addressing the challenge *Field Shift: Adapting Farms with NASA Data*.

The application uses environmental and geospatial data, including information provided by NASA, to help farmers understand climate conditions and evaluate agricultural adaptation strategies.

**Key Features:**

- Integration of environmental and geospatial data.
- Application of artificial intelligence to agricultural data analysis.
- API development and service integration.
- Transforming environmental data into useful insights for agricultural planning.

🔗 [**GitHub Repository**](https://github.com/eeomts/FieldShift-NasaSpaceApps-Hackathon)
